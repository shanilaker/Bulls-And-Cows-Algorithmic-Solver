# Bulls and Cows Solver

A C++ program that automatically solves the "Bulls and Cows" code-breaking game.

## Game Setup (User Inputs)
When you run the game, you need to enter 4 simple settings:
1. **Code Length (n):** How many digits make up the secret code.
2. **Max Digit (k):** The highest number allowed in the code.
3. **strategy_num (1 or 2):** The brain the computer uses to solve the game (DFS or BFS).
4. **Random Seed:** A starting number to shuffle the secret code.
